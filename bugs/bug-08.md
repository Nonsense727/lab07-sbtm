# BUG-08: Footer дахь «Хуучин хувилбар» линк 500 Internal Server Error буцаана

Орчин:  Уншлагын жагсаалт v2.0, Google Chrome for Testing 153.0.8010.12, macOS 27.0.1, 2026-10-22
Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. `node app.js` ажиллуулаад браузераар http://localhost:3000 нээ.
2. Хуудасны доод хэсгийн «Хуучин хувилбар» линк дээр дар.
3. Эсвэл терминалд: `curl -i http://localhost:3000/old`

Хүлээгдэж байсан: «бүх хуудас, линк ажиллана» — линк нь ажиллах хуудас (200)
эсвэл зөв 404 буцаах ёстой.
Бодит үр дүн:     `HTTP/1.1 500 Internal Server Error`, биет нь «Internal Server
Error» гэсэн энгийн текст. Хэрэглэгч аппын алдааны хуудас руу орно.

Ноцтой байдал: Major — хэрэглэгчид харагдах линк бүхэлдээ эвдэрсэн; серверийн
талын алдаа (500) нь хэрэглэгчид «апп эвдэрсэн» гэсэн сэтгэгдэл төрүүлнэ.
